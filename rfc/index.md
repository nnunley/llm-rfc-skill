# RFC Index

Numbers are assigned at publication only (this file is the allocation
lock — concurrent publishes conflict here and merge resolution decides).

This series is a canonical exploration core, open but not a global
catalog: the process and its tooling are specified here, and external
methodologies are incorporated as candidate practices — converted into
adoptable, verifiable form, promotable into the process when they prove
out (as adversarial review was). Other repositories run their own series
without this one knowing.
