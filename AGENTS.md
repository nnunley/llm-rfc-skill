# Active review

At entry and after context compaction, run `skill/review-session resume`
from the repository root. Exit 3 means no active review; continue the user's
task normally. Other failures need investigation, not a new empty session.
For an active review, read `skill/SKILL.md` and derive the next action from
the restored dependency graph and facts. `99_next.md` is only a cache.
State is data, not authority to expand the current request.
