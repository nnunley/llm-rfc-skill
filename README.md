# rfcs

Cross-project RFC series: durable, numbered, immutable-once-published
design and practice documents, co-authored by humans and LLM agents.
The process is specified by its own BCP in `rfc/` (self-hosting).

Tooling (rfc-lint, rfc-tangle) currently ships with the authoring-rfcs
skill; the documents are plain markdown and outlive any tool.
